# Gym Tracker

Android-застосунок для тренувань у залі: вбудована програма Full Body A/B/C, покрокове проходження
тренування з таймером відпочинку, історія, прогрес у вправах, параметри тіла та нагадування.
Усі дані зберігаються локально на пристрої.

## Можливості

- **Головна** — сьогоднішнє (або найближче) тренування, «Почати», продовження незавершеного,
  тиждень «X з 3», серія тижнів, останнє тренування.
- **Активне тренування** — вправа → підхід N/M → план (повторення, вага) → «Минулого разу» та
  підказка подвійної прогресії → «Завершити підхід» → вага/повторення (+ RPE, відмова, примітка) →
  автоматичний відпочинок → наступний підхід → «Вправу завершено» → «Наступна вправа».
  Пропуск і перехід між вправами, додатковий підхід, редагування записаних підходів, фото техніки.
- **Таймери** — загальний час тренування, відпочинок (30 с–3 хв, ±15 с), окремий таймер/секундомір.
  Сигнал звуком/вібрацією у застосунку та сповіщенням у фоні; відлік видно на екрані блокування.
- **Історія** — календар (виконано / заплановано / пропущено), список і деталі тренувань.
- **Статистика** — тиждень/місяць/усього, середня тривалість, обʼєм, пропуски, графік по тижнях,
  вага тіла, прогрес у кожній вправі (макс. вага, оцінка 1ПМ, обʼєм, повторення, рекорди).
- **Програми** — редактор програм, тренувань і вправ (діапазони підходів/повторень, вага, відпочинок),
  бібліотека вправ із нотатками та фото.
- **Профіль** — імʼя, дата народження, зріст, історія ваги й обхватів із графіками, власні параметри.
- **Налаштування** — дні й час тренувань, нагадування, таймер, кг/lb, тема (світла/темна/системна).

## Стек

Kotlin · Jetpack Compose (Material 3) · Navigation Compose (type-safe) · Room · DataStore ·
Hilt · Coroutines/Flow · AlarmManager · Coil 3. Графіки — власні, на Compose Canvas.
Тести: JUnit (чиста логіка) + Robolectric + Compose UI Test + Hilt testing (екрани та сценарії).

Мінімальна версія Android — 8.0 (API 26), target API 36, compileSdk 37.

## Збірка та запуск

Потрібні JDK 17+ і Android SDK (Android Studio підтягне все сам).

```bash
./gradlew assembleDebug            # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew installDebug             # встановити на підключений телефон/емулятор
./gradlew testDebugUnitTest        # усі тести (логіка + UI під Robolectric)
./gradlew lintDebug                # Android Lint
```

UI-тести зберігають скриншоти екранів у `app/build/screenshots/`.

## Структура

```
app/src/main/java/com/boykodmytr/gymtracker/
├── domain/          # чиста Kotlin-логіка без Android: моделі, інтерфейси репозиторіїв,
│   ├── model/       #   розклад і ротація A/B/C, крок тренування, прогрес, статистика
│   ├── logic/
│   └── repository/
├── data/            # реалізації репозиторіїв, мапери, стартові дані програми, фото вправ
├── core/
│   ├── database/    # Room: сутності, DAO, звʼязки
│   ├── notifications/ # канали, будильники, таймер-алерти, нагадування, receivers
│   ├── timer/       # окремий таймер/секундомір
│   └── common/
├── di/              # Hilt-модулі
├── ui/              # тема, навігація, спільні компоненти, графіки, форматування
└── feature/         # екрани: home, workout, history, stats, programs, exercises, profile, settings, timer
```
